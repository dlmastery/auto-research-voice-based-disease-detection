# Quarantine — results this program has WITHDRAWN

A program that cannot retract cannot be believed. When a result is found to be
invalid (reward-hacked metric, leaked split, confound-driven, instrument artifact,
unreproducible), it is moved here with a `WHY_QUARANTINED.md` stating:

1. the original claim, verbatim, and where it was published in this repo;
2. what was wrong, with the evidence that established it;
3. what was done to prevent recurrence (rule added / code fixed);
4. the date and the commit that withdrew it.

Quarantined results are NEVER deleted — the record of the retraction is itself a
finding. This directory is modelled on the best artifacts in the prior autoresearch
lineage (`_quarantined_reward_hack/`, `_quarantined_blind_sweep/`).
